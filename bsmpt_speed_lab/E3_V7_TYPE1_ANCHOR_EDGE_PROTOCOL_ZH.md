# Region-v7 type-I认证盒外沿对抗协议

预注册日期：2026-09-08

本轮只研究Yukawa type-I，并保持region-v7实现和阈值冻结。目的不是扩大规则，而是把
样本推到B10/A9晚期失败锚点的现有认证半径附近，主动寻找严格正/失败翻转、近似分类
错误、温度计数跨越以及路由意外接受。

## 冻结验收条件

1. 先完成全部strict，再运行当前冻结v7；外层最多两个CalcGW。
2. 裸近似和v7最终结果都分别报告TP/TN/FP/FN；被v7接受的点必须FP=FN=0。
3. 若严格出现正点，v7必须严格回退或给出正SNR；任何接受后的FN立即撤销对应锚点。
4. 若近似失败阶段与严格阶段不同，即使正/失败结论一致也必须单独报告。
5. 本批不得扩大锚点半径、不得提高`temperatures<=6`阈值、不得提出全type-I外推。
6. 只有分类零错误且被接受子集端到端耗时至少降低20%，才保留当前证书的外沿证据。
7. Q1只有实际观察到温度数6与7或更高的相邻括号，才允许讨论阈值边界；否则只记为
   负结果。首次反例必须strict和裸近似各重复三次，稳定后立即收缩或撤销对应锚点。
