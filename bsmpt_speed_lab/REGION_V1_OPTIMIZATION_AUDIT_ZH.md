# region-v1 下一步优化审计（2026-09-05）

## 不变约束

- 所有实现和测试只允许位于 `bsmpt_speed_lab`，严格版与主项目不得修改。
- 非严格版的首要判据是定性一致：严格版有限 `SNR > 0` 时非严格版也必须为正，
  严格版失败/非正时非严格版也必须失败/非正。认证域内必须 `FP=FN=0`。
- classified 数据只用于发现反例与补充压力样本，不能证明全参数空间安全。
- CalcGW 并发数不超过 2。

## 当前性能瓶颈

42 点 region-v1 已测为 `TP=20, TN=22, FP=0, FN=0`。严格总耗时
2173.759 s；region-v1 最终输出中的 runtime 合计 1485.935 s，但两次 L1 后
严格回退覆盖了 42.153 s 的首遍耗时，因此真实端到端为 1528.088 s，提升
29.70%。路由为：36 点接受，4 点 direct exact，2 点 post-L1 exact。

真正的大头不是约 1.05 s/点的 legacy shadow，而是严格回退，尤其 broad-B 第3、
4点：严格耗时分别约 176 s 与 405 s。它们是严格 TP，但单温 shadow 假拒绝；即使
把 `max_path_integrations` 从 2 加到 7 仍不成功。

## 候选 O1：把已知必回退点前移到 R0

`approx_exact_direct_anchors.tsv` 当前已经加入 broad-B 第10点和 NLO-valid 第4点的
零半径锚点。下一轮它们会在 L1 前 direct exact，避免已知的 29.020 + 13.133 =
42.153 s 无效首遍。

- 正确性风险：无；最终仍调用严格版。
- exact 比例：仍为 6/42，只改变执行顺序。
- 按同批计时的端到端估算：1485.935 s，比严格版快 31.64%。
- 验证：单点确认两条路由均为 `direct exact` 且输出除 runtime 外与严格参考逐字段
  一致；之后更新完整 42 点路由统计。禁止把零半径锚点外推成未经验证的区域。

## 候选 O2：多温度 legacy shadow，减少昂贵 TP 回退

当前 shadow 只选 `SolutionList` 中 `|S/T-140|` 最小的一个温度。建议添加纯诊断模式：
按 `|S/T-140|` 排序，测试中心点及其相邻的最多两个不同温度，记录每个温度的成功、
action、路径迭代数和耗时，不立即改变生产路由。

目标是判断 broad-B 第3、4点的 shadow failure 是否只是单温度/单路径选择问题。已有
broad-B 第8点 FP 在多个温度连续路径形变仍失败，因此它是首要反例。候选证书只能用于
L1 positive；L1 late failure 仍必须 exact，因为现有危险邻域中已有 FN。

- 第一阶段：B3、B4（昂贵 TP），B8（已知 FP）和 central2 危险邻域4点。
- 第一阶段门槛：B3/B4 至少救回一个，同时 B8 与所有严格 negative 不得出现可接受
  证书；否则淘汰或收紧规则。
- 第二阶段：42点全量以及每个已知危险点的独立局部扰动邻域，输出混淆矩阵和路由。
- 第三阶段：至少三个物理上不同的新增局部区域；每一区域单独要求 `FP=FN=0`，不能
  只报告合并结果。
- 潜在收益上限：若 B3/B4 都能安全接受，可避免约 581 s 严格计算；以现有批次粗估，
  端到端提升可能接近 58%，但在通过新增邻域前不得把该数字作为实测结果。

应依次比较保守规则：中心成功；中心与一个邻点均成功；三个温度全成功。`any-success`
只能作为反例发现用的宽松消融，不能未经 negative 邻域证明直接成为生产证书。

## 候选 O3：安全域内跳过 shadow

高 SNR 锚点 `1e-4` 邻域22点已得到严格/非严格全 positive、shadow 22/22 success，
但 shadow 平均仅 1.05 s，约为严格均值的 1.40%。即使完全去掉，其收益也远小于减少
一次严格回退。因此仅在多个半径壳层和方向都达到零 FP/FN 后，才考虑为该局部认证域
建立无需 shadow 的快路由。认证盒必须有明确中心、尺度、版本和外部自动 exact 行为。

## 当前不值得优先的方向

- 单纯优化 shadow：每点约 1 s，收益太小。
- raster500 降到 250/100：既有测试只再快约 3--6%，却扩大未覆盖风险。
- 输入参数全局分类器：现有 classified 样本有 thdmtools 选择偏差，只能用于选取压力点，
  不能作为生产路由或全空间安全证明。
- 放宽 late-failure 接受：已知邻域存在 FN，违反首要定性判据。

## 推荐执行顺序

1. 验证 O1 两个 direct-exact 新锚点并刷新 42 点端到端统计。
2. 实现 O2 的只诊断多温 shadow，先跑7个最有信息量的点，不改路由。
3. 若能区分昂贵 TP 与已知 negatives，再扩大42点和三个独立局部邻域；否则停止该
   分支，保留反例记录。
4. 扩大 O3 高 SNR 局部域的半径壳层；只有逐区域 FP=FN=0 才允许减少 shadow。
