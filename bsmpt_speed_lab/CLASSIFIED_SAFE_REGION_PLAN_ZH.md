# 基于 classified 数据的近似 CalcGW 辅助研究（旧口径已纠正）

> **2026-09-05 更正：** 本文早期把 `th_passed=true` 和thdmTools允许分支错误地
> 写成安全区域前提，该口径全部作废。classified 是经过上游选择的有偏样本，只能
> 作为 E1 辅助测试，不能覆盖完整 BSMPT 参数空间、定义生产路由或报告总体错误率。
> 后续强制遵循 `BSMPT_OPTIMIZATION_AND_BIASED_DATA_PROTOCOL_ZH.md`。

## 口径

本文已有24点结果只估计

`P(近似 CalcGW 可接受 | 该批有偏历史样本且 CalcGW 输入完整)`。

当前流水线在 thdmTools 判负后不运行 CalcGW，因此 `neither` 主要是“上游拒绝/未
计算”，不能作为近似 CalcGW 的失败标签；`gw_only` 是旧流程遗留，单独隔离。

“安全”必须由同一点的近似/严格配对定义：状态、有限值掩码、相变历史和相变块数
一致，并且每个总 SNR 分量相对误差不超过 10%。弱信号或严格值为零的点不能仅用
相对误差定义，应标记为 `exact_direct` 或 `unknown`。

## 只读审计结果（2026-09-05）

- 三台机器共有 4511 个 classified CSV，统一为 297 列。
- `both`：262884 行具有完整 CalcGW 输入/输出字段。
- `thdmtool_only`：181227 行具有完整 CalcGW 字段，主要用于无信号及状态边界验证。
- office 的一部分旧记录缺少可映射的 source；首轮高可信测试不使用这些行。
- 环境报告显示 CalcGW 基本对应 BSMPT commit `04cb17d1`，但工程 commit 和构建
  环境并非完全一致，所以训练/验证必须按 source 和机器整组留出。

以下范围只描述历史采样集中区，不是 BSMPT 安全域，禁止用于生产路由：

- light：`62 <= mH < 125` 且 `0.06 <= sba <= 0.21`
- heavy：`125 <= mH <= 500` 且 `0.99 <= sba <= 0.999`
- `0.3 <= sba <= 0.9` 中基本没有 thdmTools 允许点。
- EWPO 允许点集中于 `mA` 与 `mHc` 接近的谷，但谷边缘仍需严格路径。

## 验证设计

`sample_classified_safe_candidates.py` 只读 `both` 和 `thdmtool_only`，要求
`th_passed=true`、CalcGW 输入完整、source 可追溯，并按以下维度作确定性哈希蓄水抽样：

- light/heavy 分支；
- Yukawa 1--4；
- office/qiushi/yuanyuan；
- interior、physical_boundary、numeric_boundary、strict_negative。

输出包括 CalcGW 输入、全部 297 列严格参考、逐行源文件与行号，以及完整计数摘要。
分片不视作独立实验；后续按 source/run、机器和参数局部簇切分训练/校准/最终测试。

一个局部区域只有在至少 20 个独立点、3 个 source 组和 2 台机器上均无状态/历史
翻转且全部 SNR 误差小于 10% 时，才可暂称候选安全区。若要声称错误率低于 1%，
零失败情况下仍至少需要约 299 个独立测试点；因此首批 240 点只能筛选和淘汰规则，
不能给出全局安全保证。

## 旧路由原则（作废，不得实现）

1. 下列条目仅保留用于审计错误演变，不能作为后续方案。
2. 未落入已知允许分支：不启用近似。
3. 多步相变、状态异常、弱/零信号、数值或物理边界：直接严格计算。
4. 只有配对数据证实的局部高纯度区域才启用近似。
5. 近似结果还需通过在线状态、有限值和敏感性证书，否则立即回退严格计算。

  会保留行尾 `\\r`，从而破坏 TSV 结构；所有生成文件现强制 LF，旧先导输出不计入
  物理/误差统计并由同样本重跑。
- 2026-09-05：LF 修正版先导完成。23/24 点满足配对数值条件；唯一反例位于 light
  物理边界，SNR 最大相对误差为 54.9%。19 个弱/零信号点虽未翻转状态，但不进入
  安全路由；4 个有信息量的接受点误差约为 0.015%、0.45%、5.29%、0.043%。反例
  尚需当前严格快速版复算，以区分近似误差和历史构建漂移。
- 2026-09-05：当前 exact-fast 对该反例复算后，与历史严格结果的最大 SNR 分量差异
  仅 0.0281%；当前近似相对当前严格仍偏差 54.95%。因此该反例确认属于近似算法，
  不是 classified 归档或构建漂移。light 物理边界继续固定走严格路径。
