# 纯 BSMPT 优化与有偏历史数据使用规约

更新日期：2026-09-05。本文件是后续严格/非严格优化、安全区域研究和统计表述的
强制规约。若其他实验室文档与本文件冲突，以本文件为准。

## 1. 不可绕过的边界

最终运行流程只允许依赖 BSMPT/CalcGW。不得调用 thdmTools，不得把 `th_passed`、
任意 `th_*` 字段、classified 文件类别或由它们派生的判断用作优化开关、安全路由
特征、正确性标签或运行时回退条件。

MultiNest classified 数据经过 thdmTools 前置选择，缺失并非随机：大量被拒绝点根本
没有 CalcGW 结果，不同扫描系列还集中在不同参数支和目标分布。因此该数据是有偏
历史样本，不代表完整 R2HDM/BSMPT 参数空间。基于它得到的通过率、错误率、参数范围
和机器学习指标均不得表述为全空间结论。

## 2. 历史数据允许和禁止的用途

允许：

1. 逐行确认 CalcGW 确实运行后，把已存严格输出作为辅助参考，只补跑近似版。
2. 发现状态翻转、SNR超限和慢点等反例；反例一经当前严格版复核即可登记为风险锚点。
3. 估计候选算法在这批有偏分布中的运行时间，设计后续纯BSMPT分层和边界扰动。
4. 检查跨source、机器、相变状态和信号量级的基本可复现性。

禁止：

1. 用 `th_passed=true` 或 `both/thdmtool_only/gw_only/neither` 定义安全性。
2. 把未运行 CalcGW 的空白/NaN 行当作 BSMPT 或近似失败。
3. 从历史样本密集区直接推导上线安全区，或在无数据处外推。
4. 用随机逐行切分掩盖同source、同扫描链和相邻点的数据泄漏。
5. 用历史集零失败声称总体失误率上界。

纳入历史辅助池的唯一物理条件是：BSMPT输入完整，并存在可验证的CalcGW实际执行
证据（runtime/核心状态/活动相变块），且版本和选项可追溯。类别只可用于定位文件和
解释缺失机制，进入池后不得成为特征。

## 3. 三层证据体系

### E1：有偏历史辅助集

来自 classified 和既有 `bsmpt_speed_lab` 配对。用途是快速淘汰算法、找反例、建立
候选局部邻域。E1 通过不能扩大安全区，E1 失败可以直接否决或收缩候选。

### E2：纯 BSMPT 定向验证集

不经过thdmTools，由BSMPT输入空间直接生成：覆盖E1候选邻域内部、边缘、最近反例
方向、质量简并、零质量/thermal分段、NLO边界、单步/多步切换和弱/强信号变化。
每一点运行当前严格快速版与单一近似候选。E2决定局部安全边界，但仍属于主动选择集。

### E3：独立纯 BSMPT 确认集

在实验前冻结生成规则和随机种子；不使用E1/E2标签调参。按完整目标参数域分层，保留
一定比例均匀/对数探索点，并整组留出参数空间网格块。只有E3能用于报告目标分布上的
接受率、漏放率和置信上界。目标分布必须随报告明确给出，不能称为“全参数空间”而不
定义测度。

## 4. 严格快速版优化方案

严格路线不需要安全区域，所有点始终启用；要求除runtime外逐字段一致。按收益/风险：

1. S1 同点确定性重复求值消除：缓存 `LocateMinimum` 循环条件与循环体重复gradient。
2. S2 dense-threshold固定索引并行：worker写预分配槽，主线程按原索引选择。
3. S3 raster固定索引并行：只并行独立VEff/dVdl求值，spline构造与归并保持原顺序。
4. S4 action积分项并行计算、原序累加；仅在画像确认占比后实施。
5. S5 多coexistence pair粗粒度并行，单pair禁用，且不与内部线程池嵌套。

每项单独开关，先计数/画像、再最小实现；严格二进制和原版目录不修改。峰值RSS达到
18GB立即停止，外层最多两个CalcGW，内部并行测试时只运行一个。

## 5. 非严格多保真优化方案

每个算法分别建立安全标签，禁止一开始捆绑：

1. G1 coarse/fine双分辨率bounce：先低密度raster/action节点，再用独立midpoint和
   残差估计；证书失败运行高精度或exact-fast。
2. G2 温度continuation：复用profile、射击括区间和最佳尺度；先验证包根、ODE残差、
   边界、单调性、virial与法向力，失败冷启动。
3. G3 safeguarded Brent/Illinois射击：始终保留undershoot/overshoot括区间，残差
   不连续或候选出界立即二分。
4. G4 adaptive raster/action温度节点：用端点/中点真实求值验证插值；曲率、符号变化、
   零点、质量阈值附近递归细分，不能建立证书则完整回退。
5. G5 SpectrumJet方向导数：简并、过零、CW/Daisy/thermal分段附近强制原差分复核。

输入路由只能使用BSMPT输入或由其低成本确定性计算得到的量；输出证书只能使用本次
近似BSMPT的状态、残差、双分辨率差异和阈值距离。历史SNR和严格状态不能在生产时用。

## 6. 安全标签和局部区域

同一点仅在以下全部成立时标为 `safe`：

- status、活动相变块数、有限值掩码和 `transition_history` 与严格版一致；
- 每个有效总SNR及其col/sw/turb分量相对误差不超过10%；
- 关键温度、alpha、beta/H未触发独立敏感性/残差上限；
- 近似确实被接受，未用严格回退伪装成近似成功。

严格值接近零时相对误差无意义，标为 `weak/unknown -> exact`。任一状态翻转、假信号、
漏信号或SNR超限均为 `unsafe`。

安全区域采用局部锚点+标准化距离/椭球，不使用全局矩形：邻域必须有E2支持、与最近
unsafe点保持缓冲、超出覆盖凸包即unknown。至少20点/3局部簇只是候选门槛；上线前
还需E3独立确认。Yukawa、相变模式等未覆盖层绝不跨层外推。

## 7. 统计与性能门槛

分别报告E1/E2/E3，不得合并成一个成功率。核心指标为：unsafe漏放率、safe接受率、
状态翻转率、SNR超10%率、unknown/回退率，以及按source/空间块的最坏组结果。

零失败时若要在独立同分布试验中给出约95%置信的错误率低于1%，至少需要约299个
有效独立样本；这仍只对应明确定义的E3目标分布，不代表数学意义上的连续全空间。

端到端收益按

`T = T_router + T_approx + P(fallback) * T_exact`

计算。候选必须在E2和E3上均有至少2%的总墙钟收益；高回退导致比直接exact-fast慢
时立即淘汰。报告需同时给出近似首遍加速和端到端加速，禁止只报前者。

## 8. 固定执行顺序

1. 修复历史辅助池：忽略thdm判定，逐行认证CalcGW是否运行，合并已有严格/近似配对。
2. 对当前guarded算法形成E1覆盖矩阵，只用于找反例和确定E2采样预算。
3. 严格路线先做S1计数与单变量实验；同时设计E2生成器但不混合候选开关。
4. 优先测试G1双分辨率证书，因为它同时提供速度和当前点的内部误差信息。
5. 对每个候选执行E1淘汰、E2边界扩展、冻结规则、E3确认。
6. 只有通过E3和端到端门槛才接入研究版router；最终入选物理点仍可严格复核。

每轮记录假设、唯一变量、数据层级、生成规则、反例、状态/SNR、运行时间、RSS、回退率、
结论、产物、commit和push状态。失败轮次同样保存。
